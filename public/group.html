How FairShare works

1. Zero Accounts Required: The group link is your bearer token. Anyone with the URL can view and add expenses.

2. Exact Paise Arithmetic: All financial splits avoid floating point errors. Leftover paise are allocated deterministically using the largest-remainder method.

3. Greedy Debt Minimization: Settle Up simplifies mutual IOUs so your group pays each other in the absolute minimum number of payments.
